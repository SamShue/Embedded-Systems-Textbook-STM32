Place original Word (.docx) chapter drafts and their diagram source files
(e.g. `.pptx`) here, organized per chapter, if you choose to draft chapters
in Word before converting them to Quarto markdown.

This is optional: you can also write `.qmd` chapters directly in
`book/chapters/` without ever using this folder.

See the root [README.md](../README.md) for the conversion workflow.
